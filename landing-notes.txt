Refleksi Landing Page - Immanuel Library (Bagian 1)

1. Apa keuntungan memisahkan header dan footer menjadi file component tersendiri,
dibandingkan menuliskannya langsung berulang-ulang di index.php?
Jawaban: Memisahkan header dan footer membuat kode lebih efisien dan terorganisasi karena perubahan cukup dilakukan di satu file untuk memperbarui seluruh halaman, menjaga konsistensi tampilan, serta menghindari duplikasi kode yang tidak perlu.
2. Perhatikan halaman-halaman admin (Buku, Kategori, Penulis, Pengguna, Profil) pada
Bagian 2 - bagian mana pada halaman-halaman tersebut yang mengalami masalah yang sama
seperti header/footer sebelum dipisah?
Jawaban: Kedua elemen tersebut biasanya berisi struktur yang identik di setiap halaman admin—seperti logo, daftar menu navigasi (Buku, Kategori, Penulis, Pengguna, Profil), serta info profil/tombol logout. Jika ditulis langsung berulang-ulang di setiap file halaman, maka setiap kali ada perubahan menu, Anda harus mengedit semua file admin satu per satu.
